# Podium

A Next.js application with Vercel Web Analytics configured.

## Getting Started

### Development

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Build

```bash
npm run build
```

### Deploy

Deploy to Vercel:

```bash
vercel deploy
```

After deployment, enable Web Analytics in your Vercel dashboard:
1. Go to your project dashboard
2. Navigate to Analytics
3. Click "Enable" in the header

## Features

- ⚡️ Next.js 16 with App Router
- 📊 Vercel Web Analytics integrated
- 🎨 TypeScript support
- 🔍 ESLint configured
